## FastConduct v1.2

### What's New

- **Robust CIF reader** — `loop_` tags written on one line (GSAS2CIF, FullProf), rows of neighbouring
  data loops are no longer read as atoms, several `data_` blocks, Cartesian coordinates
  (`_atom_site_Cartn_*`), positions on the cell boundary merged correctly, and the number of atoms is
  cross-checked against `_chemical_formula_sum`. Checked on 28 CIF files from different sources:
  all read correctly (previously 26/28).
- **CIF export** — real cell angles for hexagonal / monoclinic / triclinic cells (plus `_cell_volume`);
  previously `alpha/beta/gamma` were always written as 90°, which made the exported structure
  unusable for DFT.
- **`Hw` convention for guest-water protons** — label the two H atoms of each water molecule as `Hw`
  in the CIF, select `Hw` as the working ion with charge +1, and structural C–H / N–H / O–H groups
  stay out of the jump network. The helper script `mark_water_h.py` performs the relabelling
  (and the reverse conversion before DFT).
- **"Save plot → PDF"** works again.

### Known limitation

CIF files that contain only the space-group symbol and no explicit symmetry operations are still
loaded as the asymmetric unit. The program now warns about this and cross-checks the atom count
against the formula, so the problem is visible instead of silent.
