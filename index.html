Ionic Conductivity Calculator using kMC

FastConduct enables rapid calculation of ionic conductivity in solids using the kinetic Monte Carlo (kMC) method. The user can specify migration barriers and vacancy concentrations directly in the structure.

Python kMC VASP CIF

📄 GitHub Repository  |  📘 User Manual

⚡ Quick Start

  1. Download FastConduct_v1.1.exe
  2. Run the executable (no install)
  3. Load a structure (POSCAR/CIF)
  4. Set parameters & run simulation

✨ Key Features

📂 Multi-format

Supports VASP POSCAR/CONTCAR and CIF files with automatic symmetry detection.

⚛️ BKL kMC Algorithm

Bortz–Kalos–Lebowitz kinetic Monte Carlo for accurate jump dynamics.

📊 Arrhenius Plots

Automatic visualization with linear fit, error bars, and conductivity data.

🧬 Ion-ion Repulsion

softBV-style repulsion model with configurable alpha and cutoff.

💾 CIF Export

Save vacancy-containing structures for further DFT calculations.

🖥️ User-friendly GUI

CustomTkinter-based interface with responsive design and progress tracking.
